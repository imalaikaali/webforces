# LogiPulse — Webforces

A collaborative full-stack courier and last-mile delivery platform, built by Team ByteWise.

## Stack
- React + Vite (frontend)
- CSS (styling)
- Backend: TBD by team

## Features
- User, Rider, and Admin dashboards
- Live order workflow
- Nearby pickup logic (color-coded by distance)
- Real-time chat UI
